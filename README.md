# Riskviza

Riskviza is a polished SaaS website for an EU-focused risk intelligence startup.

The site presents Riskviza Register, Riskviza Evidence, and Riskviza Vendors with product dashboards, motion details, pricing, solutions, company information, sign-in, and request-demo pages.

## Tech Stack

- React
- Vite
- GSAP
- Lucide React
- Simple Icons

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
